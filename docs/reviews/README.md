# 외부 모델 검토

Claude가 작성한 계획·코드·디자인을 다른 모델(Gemini, GPT 등)이 검토할 때 쓰는 폴더다.

## 진행 방식

1. Claude가 검토가 필요한 지점에서 요청서를 만든다: `docs/reviews/YYYY-MM-DD-<주제>.md`
2. 사용자가 요청서를 검토 모델에 전달한다. 요청서는 저장소 링크만으로 읽을 수 있게 쓴다.
3. 답변은 같은 파일의 `검토 결과` 절에 모델 이름과 함께 붙인다.
4. Claude가 각 지적에 대해 반영·보류·반대를 이유와 함께 `대응` 절에 적는다.

## 요청서 양식

```markdown
# 검토 요청: <주제>

- 요청일: YYYY-MM-DD · 단계: M0-a 등 · 상태: 요청 / 답변 받음 / 종결
- 대상: <파일 경로 또는 PR 링크>

## 배경
검토자가 이 저장소를 처음 본다고 가정하고 3~5줄로 설명한다.

## 검토 대상
무엇을 봐야 하는지, 무엇은 범위 밖인지.

## 질문
1. 구체적인 질문. "괜찮나요?"가 아니라 "X 상황에서 Y가 깨지지 않나?"처럼 쓴다.
2. ...

## 이미 고려한 것
같은 지적이 반복되지 않도록, 검토했지만 택하지 않은 대안과 이유.

## 검토 결과
### <모델 이름>
(답변 붙여넣기)

## 대응
| 지적 | 결정 | 이유 |
|---|---|---|
```
